Your trip brief

Example: “one week in Istanbul, two adults, honeymoon, want history and food, budget $1,500”.

Runs entirely in your browser. No account, no key, nothing stored.

What it does, honestly

This is a rules engine: it reads your words for a city, a vibe and a budget, then builds a skeleton itinerary with indicative costs. It is fast, private, free and never invents a live fare. When an LLM key is configured on the server, the same interface upgrades to a richer parser — the output schema and the rule that prices come only from suppliers do not change.

What it will not do

  • It will not book anything. It hands you a search and a WhatsApp hand-off.
  • It will not promise a price. Every number it shows is indicative.
  • It will not send your text anywhere. There is no API call in this version.

Then what?

Take the suggested search into flights or stays, or send the plan to our team and get a written quote with the fee included. Read how pricing works first if you want the arithmetic.

Planner questions

Does the planner invent prices?
No. It uses a route model and clearly labels the numbers indicative. Live prices come only from suppliers, and nothing is bookable until a person confirms it.
Does it need an API key?
The version on this site runs on a local rules engine, so it works with no key and no data leaves your browser. An LLM-backed version activates when a key is configured.
Can I speak instead of typing?
Yes. The brief field accepts dictation in Chrome and Edge through the browser speech API.
