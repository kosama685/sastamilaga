What was deployed

  • Aligned the origin and Cloudflare robots policies. Public HTML, CSS, JavaScript, cart, checkout and account pages are crawlable; private checkout/account pages retain noindex.
  • Canonical links are present in the original response head. Removed the injected canonical synchronizer. Both global catalog aliases consolidate to the established canonical category URL; public edge navigation uses its canonical version.
  • Corrected the Ronin cable watch URL to its verified static product and the jeans feed URL to its mapped fashion category. All four supplied redirect examples reach self-canonical HTTP 200 targets in one hop.
  • Installed a narrow WAF exemption for Cloudflare-verified Google crawlers whose IP is in Google's published common-crawler ranges. 317 ranges were collapsed into 59 equivalent ranges without widening the address set. Private paths and transactional requests are excluded; existing rules remain.
  • Added public blog caching and a genuine published-archive fallback for the index during a D1 outage. Individual unavailable articles are not replaced with unrelated content.
  • Refreshed stale currency data through the existing verified provider, restoring CJ shipping quotes. Installed and tested a provider-only refresh every 12 hours, independently of the overdue WordPress cron queue.

The CSS/JS structure was preserved. No new frontend script, stylesheet or render-blocking request was added by the SEO patch. No WooCommerce product page link was added to the storefront. Cart, checkout, payment and supplier shipping routes keep their existing WooCommerce handlers.

Exact coverage and exceptions

All 794 supplied examples were processed before and after deployment. There are 791 literal URLs and 3 wildcard patterns. Final browser and Googlebot user-agent outcomes match: 747 HTTP 200, 43 HTTP 410, one HTTP 404. Transaction examples used HEAD probes; that is not proof that a transaction URL should be indexed.

The 199 robots examples comprise 198 cart-action URLs and an account wildcard. All literal examples are crawlable under the final Googlebot robots policy. Cart actions, cart, checkout and accounts are not intended search results.

Of the 21 canonical examples, 17 reach an indexable static page with one self-canonical in its raw head. Four examples, representing two product slugs, currently return 410 and have no canonical. The 43 total 410 responses come from the existing retired/unmatched public route policy; no current replacement was verified. The remaining 404 is the legacy query /ur/?post_type=product&p=63. These are listed for catalog review and are not falsely reported as fixed HTTP 200 pages.

110 unique active same-host assets return 200 with appropriate non-HTML MIME types to both agents and are robots-allowed. The sitemap index and all eight immediate child files return 200 and parse as XML; those immediate files contain no cart, checkout or account entries. This does not claim that every URL across the entire catalog has been fetched or indexed.
